# Release checklist

- [x] Maintainer identity supplied by author.
- [x] Package structure, source, help, tests and synthetic tutorial prepared.
- [x] Manuscript implementation boundaries documented.
- [x] Separate software license and manuscript/source attribution.
- [x] Local source check, fresh Windows binary installation and installed example validated; see delivered release/VALIDATION.md.
- [ ] Choose GitHub owner and repository; add real URL and BugReports fields.
- [ ] Update README with actual install URL and release status.
- [ ] Inspect repository contents before upload.
- [ ] Verify Windows/macOS/Linux CI after first push.
- [ ] Tag tested commit, publish archives, and verify external installation.

The open items concern future public hosting, not local installability.
